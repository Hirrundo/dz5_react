1. Почему clickCount не обновляет интерфейс?
Потому что обычная переменная не сообщает React об изменении.
 Для обновления интерфейса обычно используют useState.
2. В чём недостаток вывода в консоль?
Пользователь не видит результат на странице. 
Консоль удобна для отладки, но не для отображения данных пользователю.
3. Какие данные можно извлечь из объекта event?
Например, event.target.value — введённое значение поля; 
event.target — элемент, на котором произошло событие; event.type — тип события.
4. Почему React предлагает описывать события через onClick, а не addEventListener?
React позволяет объявлять обработчики прямо в JSX, рядом с элементом интерфейса. 
Так код проще читать и поддерживать, а React сам управляет подключением обработчиков.
